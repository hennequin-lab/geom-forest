A point $X$ on a sphere $S$, a plane $pi$, a line $l$ or a circle $z$ is the
single scalar equation $X dot O = 0$. A distance is $-2 X dot Y$ under a square
root. A point-to-plane signed distance is $X dot pi$. Each of these is a
[[5080aa18|polynomial]] in the coefficients, so each is a residual
you can stack, weight, differentiate and solve.

```ocaml
open Geom
let v3 x y z = Nx.create Nx.float32 [| 3 |] [| x; y; z |] in
let sc x = Nx.scalar Nx.float32 x in

let sphere = Cga.sphere ~center:(v3 0. 0. 0.) ~radius:(sc 1.) in
let plane  = Cga.plane ~normal:(v3 0. 0. 1.) ~offset:(sc 0.5) in
let objective p =
  let x = Cga.point p in
  let a = Cga.scalar_prod x sphere in    (* zero on the sphere *)
  let b = Cga.scalar_prod x plane in     (* signed distance to the plane *)
  Nx.add (Nx.mul a a) (Nx.mul b b)

let value, grad = Rune.value_and_grad' objective (v3 0. 0. 0.)
```

The design constraint that makes this work is the
[[decc193a|working representation]]: one incidence expression for
every object type. The residuals differ only in which blade you contract
against, so a task-space objective is a list of contractions and a task-space
Jacobian is their gradient.

Two things to watch. The residuals are homogeneous in each object's
representative, so normalise the objects first (`Cga.normalize_sphere`,
`Cga.normalize_plane`) or the weighting will drift with the scale
([[1d3a2467|Numerical cautions in a projective algebra]]). And a residual that is zero can also be satisfied by the
degenerate object, so constraints on a point pair or a circle should be
accompanied by a non-degeneracy check ([[f862a6f6|A point pair is a hyperbolic 2-blade]], [[35a861f2|A circle is a 2-blade]]).
