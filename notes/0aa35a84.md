A bivector $B$ generates a one-parameter group of versors through
$exp(B) = sum_(k >= 0) B^k slash k!$. When $B$ is *simple* — $B and B = 0$,
equivalently $B^2$ is a scalar — the series terminates in a closed form:

```typst
exp(B) = cases(
  cos(theta) + sin(theta)/theta B & "if" B^2 = -theta^2 < 0,
  cosh(theta) + sinh(theta)/theta B & "if" B^2 = +theta^2 > 0,
  1 + B & "if" B^2 = 0,
)
```

The three cases are the three geometries a single plane can carry. A negative
square is an elliptic rotation: that is [[b1f5db79|a rotor]]. A positive square is
a hyperbolic boost: a translation in the conformal model
([[ad74741e|A translator is a null rotation]]) or a dilation ([[20a44783|A dilation is a boost in the e4e5 plane]]). A zero square is a null
rotation: a translation again, or a transversion ([[649e54f0|A transversion bends space without moving infinity]]), or a shear.

```ocaml
open Geom

module V3 = Versor.Make (E3)

let b = E3.gp (E3.op E3.e1 E3.e2) (E3.scalar (-.Float.pi /. 4.)) in
let r = V3.exp_simple b in                 (* a 45 degree rotor *)
Nx.to_array (E3.to_vector (E3.apply_rotor r E3.e1))
```

A general bivector in five dimensions is a sum of at most two commuting simple
bivectors, so the same closed form applies after a spectral decomposition. The
library implements `exp_simple` today and stages the general
`exp`/`log` behind the `Versor` interface; the robotics path instead uses the
packed [[6132d759|`Motor.exp`]], which is the same map on a smaller algebra
([[432aee25|One motor algebra, two models]]).
