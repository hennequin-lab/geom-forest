Forward kinematics is a motor product

#ga/motion

A kinematic chain is a product of motors. For each joint with configuration , let be that joint's motor — a rotor about an axis through a point for a revolute joint, a translator for a prismatic one, the exponential of a twist for a helical one — and let be the fixed transform from the previous link frame to the joint. open Geom
let v3 x y z = Nx.create Nx.float32 [| 3 |] [| x; y; z |] in
let sc x = Nx.scalar Nx.float32 x in

let lengths = [| 0.65; 0.55; 0.45; 0.35; 0.30; 0.25 |] in
let q = [| 0.55; -0.75; 0.95; 0.35; -0.85; 0.65 |] in
let axis i = if i land 1 = 0 then v3 0. 0. 1. else v3 0. 1. 0. in
let joint i =
  Motor.mul (Motor.rotate ~axis:(axis i) ~angle:(sc q.(i)))
            (Motor.translate3 0. 0. lengths.(i))
in
let rec arm i =
  if i = Array.length lengths then Motor.one
  else Motor.mul (joint i) (arm (i + 1))
in
Nx.to_array (Cga.coords (Cga.apply_motor (arm 0) (Cga.point3 0. 0. 0.)))
(* [-0.9564, -0.2967, 2.156] *)

The order of the product matters and is easy to get wrong (Motors compose like matrices). Every operation here is a product of eight-component motors followed by a 32-component sandwich, both of which are small, batched and differentiable (The last axis is the blade axis, Traced algebra: no host branches). The chain is also a shortcut linear in each if you differentiate it with Rune.grad, which is exactly what inverse kinematics exploits.
