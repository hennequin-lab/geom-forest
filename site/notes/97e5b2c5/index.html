Write task objectives as conformal residuals

#ga/motion

A point on a sphere , a plane , a line or a circle is the single scalar equation . A distance is under a square root. A point-to-plane signed distance is . Each of these is a polynomial in the coefficients, so each is a residual you can stack, weight, differentiate and solve.

open Geom
let v3 x y z = Nx.create Nx.float32 [| 3 |] [| x; y; z |] in
let sc x = Nx.scalar Nx.float32 x in

let sphere = Cga.sphere ~center:(v3 0. 0. 0.) ~radius:(sc 1.) in
let plane  = Cga.plane ~normal:(v3 0. 0. 1.) ~offset:(sc 0.5) in
let objective p =
  let x = Cga.point p in
  let a = Cga.scalar_prod x sphere in    (* zero on the sphere *)
  let b = Cga.scalar_prod x plane in     (* signed distance to the plane *)
  Nx.add (Nx.mul a a) (Nx.mul b b)

let value, grad = Rune.value_and_grad' objective (v3 0. 0. 0.)

The design constraint that makes this work is the working representation: one incidence expression for every object type. The residuals differ only in which blade you contract against, so a task-space objective is a list of contractions and a task-space Jacobian is their gradient.

Two things to watch. The residuals are homogeneous in each object's representative, so normalise the objects first (Cga.normalize_sphere, Cga.normalize_plane) or the weighting will drift with the scale (Numerical cautions in a projective algebra). And a residual that is zero can also be satisfied by the degenerate object, so constraints on a point pair or a circle should be accompanied by a non-degeneracy check (A point pair is a hyperbolic 2-blade, A circle is a 2-blade).
