Four reading paths through the forest

#map

The forest map is a graph, not a book. These four paths are the ones that make sense; each is short and self-contained.

1. The five-minute version

Why geometric algebra: one product instead of a pile → The geometric product → Perpendicular directions anticommute → A rotor is exp(-θB/2) → The sandwich is an algebra automorphism → A motor is a dual quaternion → Distance is an inner product. Seven notes, no software, and you can read the rest of the forest afterwards.

2. From quaternions to rigid motions

For someone who already rotates things for a living. Start at Quaternions are the even subalgebra of Cl(3,0,0), the even subalgebra you already know, then Exponentiating a simple bivector closes in three cases for why the exponential closes, Rotors compose by multiplication, twice around for the double cover, A translator is a null rotation for the trick that turns translation into a null rotation, and A motor is a dual quaternion with The SE(3) exponential turns a twist into a screw for the full pose. Finish with ScLERP interpolates along the group exponential and The adjoint turns a sandwich into a matrix, which are what kinematics code actually calls.

3. The conformal model, properly

The long path, in dependency order: Cl(4,1) is the conformal model of 3D space for the ambient space, A conformal point is a null vector for the null-vector representation, Distance is an inner product for the one identity everything follows from, A sphere is a vector and A plane is a vector for the two kinds of vector object, Round versus flat: the e∞ contraction decides for the dichotomy between them, then A line is a 2-blade, A circle is a 2-blade, A point pair is a hyperbolic 2-blade and Wedge the points, then dualise for the rest of the object layer. The working representation stores the lower grade is the summary table; read it twice.

4. The software path

For the person who has to make it run: The last axis is the blade axis for the shape convention, The multiplication table is 2^n × 2^n signs for the multiplication table, Traced algebra: no host branches for what "compatible with jit" costs, Numerical cautions in a projective algebra for the traps, then The geom API map for the module layout. Matrices, quaternions, dual quaternions, geometric algebra is the honest comparison with matrices, quaternions and dual quaternions, and When the conformal model is worth it says when not to bother.
