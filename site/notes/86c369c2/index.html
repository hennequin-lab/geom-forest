For a blade in the working representation, the same contraction with the appropriate grade does the job: exactly when is flat.

open Geom
let v3 x y z = Nx.create Nx.float32 [| 3 |] [| x; y; z |] in
let sc x = Nx.scalar Nx.float32 x in

let s = Cga.sphere ~center:(v3 0. 0. 0.) ~radius:(sc 1.) in
let pi =
  Cga.normalize_plane (Cga.plane ~normal:(v3 0. 0. 1.) ~offset:(sc 0.))
in
Nx.item [] (Cga.scalar_prod Cga.einf s)    (* -1.: round *)
Nx.item [] (Cga.scalar_prod Cga.einf pi)   (* 0.: flat *)
Nx.item [] (Cga.is_round s)                (* true *)
Nx.item [] (Cga.is_flat pi)                (* true *)

The library exposes the test as boolean tensors (is_flat, is_round) rather than a host-side variant, so batching, tracing and autodiff survive (The last axis is the blade axis, Traced algebra: no host branches). Circles and point pairs are round, lines are flat; that is why the circle's carrier plane can be extracted with the same contraction (The carrier plane of a circle), and why a point pair is the zero-dimensional round object (A point pair is a hyperbolic 2-blade).
